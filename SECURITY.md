# Reporting security issues

Do not post credentials, private workspace state or customer data in issues.
Use GitHub's **Report a vulnerability** option under the repository's Security
tab if available. If private reporting is unavailable, open a minimal public
issue asking the maintainer for a private contact route without exploit details
or sensitive data. No response time or staffed security service is promised.

For accidental credential exposure, rotate/revoke the credential with its
provider immediately; removing a file does not revoke it. See
[the safety model](docs/SAFETY.md) for the kit's boundaries.
