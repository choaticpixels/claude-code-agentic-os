# Workflow map

1. /heartbeat: inspect the workspace, identify the next useful action.
2. /project-builder <request>: create or change a scoped project.
3. /project-auditor <target>: inspect implementation and verification gaps.
4. If repairs are needed, request them from /project-builder and audit again.
5. /wrap-up: preserve evidence and next actions.

Use /skill-creator when a recurring procedure deserves its own skill.
Use /system-review every 4–6 weeks or after a significant workflow change.
Each command is invoked by the user. This map is not an automatic chain,
registered schedule, agent hierarchy, or permission grant.
